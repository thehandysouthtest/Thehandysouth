# The Handy South

The Handy South helps people find the help they need.

## Current MVP

- Responsive landing page
- Help-request form
- Formspree integration
- Service categories
- Mobile-friendly layout

## Next steps

1. Put the site on a public preview URL.
2. Test requests with a small group of people.
3. Add the helper/provider side of the marketplace.
4. Add accounts, payments, matching, messaging, and reviews as the business model is validated.
